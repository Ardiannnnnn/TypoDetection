# Aset beranda

## Animasi dokumen

`src/components/review/DocumentMotion.tsx` memuat SVG/CSS yang dibuat manual
mengikuti referensi tumpukan dokumen/kaca pembesar dari pemilik. Tidak memakai
file gambar referensi, video, image generation atau library motion tambahan.
Tiga halaman berganti setiap5detik (siklus15detik), penanda merah/biru muncul,
dan kaca pembesar bergerak. Tersedia jeda/putar dan versi statis untuk
prefers-reduced-motion. Ini ilustrasi pemeriksaan, bukan status job nyata.
